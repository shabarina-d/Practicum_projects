## Automatic taxi data processing (Автоматическая обработка данных такси)

#### Цель
Cоздать таблицу, которая будет ежеденевно с актуальными данными и станет основой для финансовых отчётов и аналитических дашбордов.

#### Проделанная работа в рамках реализации проекта:
1. Построена витрина данных, которая будет агрегирует информацию о поездках на такси по каждому способу оплаты. Для этого написан PySpark-скрипт, который рассчитает ключевые показатели: количество поездок, среднюю стоимость поездки, средние чаевые и суммарную выручку по каждому типу оплаты.

2. Создан DAG в Airflow, который ежедневно:
- проверяет наличие новых файлов с данными;
- запускает Spark-задачу;
- формирует обновлённую итоговую таблицу.

#### Инструменты:
Python, Spark, Airflow, JDBC, S3 (Yandex Cloud Storage)

#### Библиотеки:
pyspark, airflow, pyspark.sql.functions
