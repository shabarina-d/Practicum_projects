## E-commerce Analytics Dashboard (Аналитический дашборд электронной коммерции)

#### Цель
Отслеживать продажи и поведение пользователей

#### Задача
Подготовить дашборд для электронной коммерции

#### Проделанная работа в рамках реализации проекта:
- подготовила вопросы к заказчику;
- провела интерьвю с заказчиком и сформировала ТЗ;
- создала прототип дашборда в Miro;
- подготовила дашборд в Superset;
- написала аналитическую записку.

#### Инструменты:
Google Docs, Superset
