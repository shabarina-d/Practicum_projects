## Данные о продажах мед. пробирок (Sales data for medical vials)

### Цель: 
отслеживать метрики по продажам мед. пробирок/
### Пользователи: 
рукодитель отдела продаж, менеджеры по работе с поставщиками и менеджеры по продажам.

### Задача: 
разработать дашборд для данных о продажах медицинских пробирок самого разного предназначения — для анализа крови, для хранения мазков ПЦР и множества других.

### Проведеланная работа в рамках реализации проекта:
- сформулировала вопросы для интервью с заказчиком;
- провела интервью и составила ТЗ;
- разработала дашборд в DataLens.

Google Docs, DataLens
