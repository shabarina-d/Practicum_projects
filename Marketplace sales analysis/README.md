## Marketplace sales analysis (Анализ продаж маркетплейса)

#### Цели и задачи: 
оперативно оценивать и контролировать динамику продаж, активности пользователей и качество товаров для принятия оперативных бизнес-решений

#### Пользователи: 
команда маркетинга, аналитики, продуктовые менеджеры, руководители направлений

### Проведеланная работа в рамках реализации проекта:
- сформулировала вопросы для интервью с заказчиком;
- провела интервью и составила ТЗ;
- создала прототип дашборда в Miro;
- выполнила предобработку данных с помощью Python;
- провела Ad-hoc аналитику, используя SQL;
- разработала дашборд в SuperSet;
- подготовила инструкцию для пользоввтелей по использованию дашборда.

#### Инструменты:
Google Docs, Miro, Python, PostgreSQL, SuperSet.
